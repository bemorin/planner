How to fix it

  • On this computer — stop the server and start it with the API: npm run start:api, then open the /admin/ address it prints.
  • In production (Cloudflare Pages) — bind the D1 database as DB, add the encrypted secret ADMIN_TOKEN, set the build variable DAILY_PLANNER_API_URL=/api, then redeploy. Step by step: docs/configuration.md.
